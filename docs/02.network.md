
# 02. Network Design

## 1. 네트워크 구성

LexiMatch 인프라는 역할에 따라 네트워크를 분리했습니다.

| 네트워크 | VMnet | CIDR | 용도 |
|---|---|---|---|
| 직원망 | VMnet10 | 192.168.10.0/24 | 직원 PC |
| 개발망 | VMnet20 | 192.168.20.0/24 | 개발자 PC |
| 서버망 | VMnet30 | 192.168.30.0/24 | DNS / WEB / WAS / DB |
| 개발서버망 | VMnet13 | 192.168.40.0/24 | 개발 서버 |

## 2. IP 구성

### GW01

| Interface | IP | 역할 |
|---|---|---|
| ens37 | 192.168.10.1/24 | 직원망 Gateway |
| ens38 | 192.168.20.1/24 | 개발망 Gateway |
| ens39 | 192.168.30.1/24 | 서버망 Gateway |
| ens40 | 192.168.40.1/24 | 개발서버망 Gateway |
| ens33 | DHCP | 외부 네트워크 |

GW01은 Routing, NAT, DHCP, Firewall 역할을 담당합니다.

### 서버

| Server | IP | 역할 |
|---|---|---|
| DNS01 | 192.168.30.10 | DNS |
| WEB01 | 192.168.30.20 | Nginx |
| DB01 | 192.168.30.30 | MySQL |
| WAS01 | 192.168.30.40 | Spring Boot |
| leximatch-server-01 | 192.168.40.10 | Development Server |

## 3. DHCP

직원망과 개발망은 GW01의 Kea DHCP를 사용합니다.

~~~text
직원망
Network : 192.168.10.0/24
Gateway : 192.168.10.1
Pool    : 192.168.10.100 - 192.168.10.200

개발망
Network : 192.168.20.0/24
Gateway : 192.168.20.1
Pool    : 192.168.20.100 - 192.168.20.200
~~~

서버망과 개발서버망의 서버는 Static IP를 사용합니다.

## 4. Routing / NAT

GW01을 통해 각 네트워크 간 통신을 수행합니다.

~~~text
직원망
192.168.10.0/24
       │
       ▼
     GW01
       │
       ├───────────────┐
       │               │
       ▼               ▼
     개발망          서버망
192.168.20.0/24    192.168.30.0/24
       │
       ▼
   개발서버망
192.168.40.0/24
~~~

각 네트워크의 기본 Gateway는 GW01입니다.

~~~text
192.168.10.0/24 → 192.168.10.1
192.168.20.0/24 → 192.168.20.1
192.168.30.0/24 → 192.168.30.1
192.168.40.0/24 → 192.168.40.1
~~~

내부 네트워크에서 인터넷으로 통신할 때는
GW01에서 MASQUERADE 기반 NAT를 적용합니다.

~~~text
Client
192.168.20.101
      │
      ▼
GW01
192.168.20.1
      │
      │ NAT
      ▼
External Network
      │
      ▼
Internet
~~~

현재 NAT 대상 네트워크는 다음과 같습니다.

~~~text
192.168.10.0/24
192.168.20.0/24
192.168.30.0/24
~~~

## 5. DNS

내부 DNS 서버는 DNS01을 사용합니다.

~~~text
DNS Server : 192.168.30.10
Zone       : momantle.internal
~~~

주요 DNS 레코드는 다음과 같습니다.

| Hostname | IP |
|---|---|
| dns.momantle.internal | 192.168.30.10 |
| gw.momantle.internal | 192.168.30.1 |
| web.momantle.internal | 192.168.30.20 |
| was.momantle.internal | 192.168.30.40 |
| db.momantle.internal | 192.168.30.30 |

## 6. 네트워크 설계 원칙

- 직원망, 개발망, 개발서버망, 서버망을 분리
- 클라이언트는 DHCP 사용
- 서버는 Static IP 사용
- GW01을 중앙 Gateway로 구성
- 내부 네트워크의 외부 통신은 NAT 사용
- 네트워크 간 접근은 방화벽 정책으로 제어
