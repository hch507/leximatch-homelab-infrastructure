최종적으로 GW01의 접근 제어 정책을 확인합니다.

### FORWARD

    Chain FORWARD (policy DROP)

주요 정책:

    ESTABLISHED,RELATED     → ALLOW

    Developer → DEV01:80    → ALLOW
    Developer → DEV01:443   → ALLOW
    Developer → DEV01:8080  → ALLOW
    Internet Outbound       → ALLOW
    Other Traffic           → DROP
