
# 03. Access Policy

GW01 게이트웨이를 중심으로 네트워크 간 트래픽 제어 정책(ACL)을 정의합니다.

최소 권한 원칙(Least Privilege)에 따라 필요한 서비스만 허용하고, 그 외의 트래픽은 기본적으로 차단(Default Deny)합니다.

---

## 1. 네트워크 제어 원칙

- **중앙 네트워크 제어:** 서로 다른 네트워크 간 통신은 GW01의 IPTables에서 제어합니다.
- **최소 권한 허용:** 업무 및 개발에 필요한 서비스 포트만 허용합니다.
- **기본 차단:** 명시적으로 허용되지 않은 네트워크 간 통신은 차단합니다.
- **상태 추적:** 기존 연결의 응답 패킷은 `ESTABLISHED,RELATED`를 통해 허용합니다.
- **서버망 내부 제어:** 동일한 `192.168.30.0/24` 내의 WEB-WAS-DB 통신은 GW01을 거치지 않으므로 각 서버의 Local Firewall에서 제어합니다.

---

## 2. GW01 접근 제어 정책

| Source | Destination | Port / Protocol | Action | Description |
|---|---|---:|---|---|
| Employee | DNS01 | 53 UDP | ALLOW | 내부 DNS 질의 |
| Developer | DNS01 | 53 UDP | ALLOW | 내부 DNS 질의 |
| Dev Server | DNS01 | 53 UDP | ALLOW | 내부 DNS 질의 |
| Employee | WEB01 | 80 TCP | ALLOW | 웹 서비스 접속 |
| Developer | WEB01 | 80 TCP | ALLOW | 웹 서비스 접속 |
| Developer | DEV01 | 22 TCP | ALLOW | SSH 원격 관리 |
| Developer | DEV01 | 80, 8081 TCP | ALLOW | 웹/CICD|
| Employee | DEV01 | ALL | DENY | 개발서버 접근 차단 |
| Internal Networks | Internet | ALL | ALLOW | 외부 인터넷 통신 |
| Other Traffic | Any | ALL | DROP | 기본 차단 |

---

## 3. Stateful Firewall

기존 연결의 응답 트래픽을 허용합니다.

```bash
iptables -A FORWARD -m conntrack --ctstate ESTABLISHED,RELATED -j ACCEPT
```

---

## 4. DNS 접근 정책

Employee, Developer, Dev Server에서 DNS01의 DNS 서비스를 사용할 수 있도록 TCP/UDP 53 포트를 허용합니다.

```bash
iptables -A FORWARD -s 192.168.10.0/24 -d 192.168.30.10 -p udp --dport 53 -j ACCEPT
iptables -A FORWARD -s 192.168.10.0/24 -d 192.168.30.10 -p tcp --dport 53 -j ACCEPT

iptables -A FORWARD -s 192.168.20.0/24 -d 192.168.30.10 -p udp --dport 53 -j ACCEPT
iptables -A FORWARD -s 192.168.20.0/24 -d 192.168.30.10 -p tcp --dport 53 -j ACCEPT

iptables -A FORWARD -s 192.168.40.10 -d 192.168.30.10 -p udp --dport 53 -j ACCEPT
iptables -A FORWARD -s 192.168.40.10 -d 192.168.30.10 -p tcp --dport 53 -j ACCEPT
```

---

## 5. Web 서비스 접근 정책

Employee와 Developer에서 WEB01의 HTTP/HTTPS 서비스를 사용할 수 있도록 허용합니다.

```bash
iptables -A FORWARD -s 192.168.10.0/24 -d 192.168.30.20 -p tcp -m multiport --dports 80 -j ACCEPT
iptables -A FORWARD -s 192.168.20.0/24 -d 192.168.30.20 -p tcp -m multiport --dports 80 -j ACCEPT
```

---

## 6. 개발서버 접근 정책

Developer에서만 DEV01의 필요한 서비스에 접근할 수 있도록 허용합니다.

```bash
iptables -A FORWARD -s 192.168.20.0/24 -d 192.168.40.10 -p tcp --dport 22 -j ACCEPT
iptables -A FORWARD -s 192.168.20.0/24 -d 192.168.40.10 -p tcp -m multiport --dports 80,443,8080 -j ACCEPT
```

Employee의 개발서버 접근은 차단합니다.

```bash
iptables -A FORWARD -s 192.168.10.0/24 -d 192.168.40.10 -j DROP
```

---

## 7. 서버 간 접근 정책

서버망의 WEB01, WAS01, DB01은 동일한 `192.168.30.0/24` 네트워크에 존재하므로 GW01의 FORWARD 체인을 통과하지 않습니다.

### WEB01 → WAS01

```text
WEB01 (192.168.30.20)
        │ TCP 8080
        ▼
WAS01 (192.168.30.40)
```

→ WAS01의 Local Firewall에서 TCP 8080을 허용합니다.

### WAS01 → DB01

```text
WAS01 (192.168.30.40)
        │ TCP 3306
        ▼
DB01 (192.168.30.30)
```

→ DB01의 Local Firewall에서 WAS01의 TCP 3306만 허용합니다.

---

## 8. Internet Outbound

내부 네트워크에서 외부 인터넷으로의 통신을 허용합니다.

```bash
iptables -A FORWARD -o ens33 -j ACCEPT
```

내부 네트워크의 인터넷 통신을 위해 NAT를 적용합니다.

```bash
iptables -t nat -A POSTROUTING -s 192.168.10.0/24 -o ens33 -j MASQUERADE
iptables -t nat -A POSTROUTING -s 192.168.20.0/24 -o ens33 -j MASQUERADE
iptables -t nat -A POSTROUTING -s 192.168.30.0/24 -o ens33 -j MASQUERADE
iptables -t nat -A POSTROUTING -s 192.168.40.0/24 -o ens33 -j MASQUERADE
```

---

## 9. Default Deny

명시적으로 허용되지 않은 Forwarding 트래픽은 기본적으로 차단합니다.

```bash
iptables -P FORWARD DROP
```

### 최종 정책 흐름

```text
ESTABLISHED,RELATED
        ↓
필요한 서비스 ALLOW
        ↓
필요한 접근 DENY
        ↓
Internet Outbound ALLOW
        ↓
Default DROP
```
