# 5. 서비스 구축 명세

## 1. 서비스 구성

| Server | Service | Port | Role |
|---|---|---:|---|
| GW01 | Kea DHCP | 67/UDP | IP 자동 할당 |
| GW01 | IPTables | - | 네트워크 접근 제어 |
| DNS01 | BIND9 | 53/UDP | 내부 DNS |
| WEB01 | Nginx | 80 | Web / Reverse Proxy |
| WAS01 | Spring Boot | 8080 | Application |
| DB01 | MySQL | 3306 | Database |
| DEV01 | SSH | 22 | 원격 관리 |
| DEV01 | Nginx | 80 | 개발/테스트 Web |
| DEV01 | Jenkins | 8081 | CI/CD |
| DEV01 | Prometheus | 9090 | Metrics 수집 |
| DEV01 | Grafana | 3000 | 모니터링 시각화 |
| DEV01 | Node Exporter | 9100 | 서버 지표 수집 |

## 2. 주요 서비스

### GW01
- Kea DHCP를 이용한 IP 할당
- IPTables를 이용한 네트워크 접근 제어
- 내부 네트워크 Routing

### DNS01
- BIND9 기반 내부 DNS 서버
- `momantle.internal` 도메인 관리

### WEB01
- Nginx 기반 Web Server
- WAS01으로 Reverse Proxy

### WAS01
- Spring Boot Application Server
- DB01의 MySQL과 연동

### DB01
- MySQL Database Server
- 애플리케이션 데이터 저장

### DEV01
- 개발 및 테스트 환경
- Jenkins를 이용한 CI/CD 구성
- Prometheus, Grafana, Node Exporter를 이용한 서버 모니터링
